과제 0 · 최우선

연구개발전담부서 등록

소요기간: 약 4~6주 비용: 무료 신청처: RNDIP (rndip.or.kr)

모든 정부 R&D 과제 신청의 필수 선행 조건. 이것이 없으면 아래 과제 1~5 신청 불가.

PHASE 1 — 준비 단계 (1~2주차)

1

연구전담요원 선정

무엇을: 연구를 전담할 직원 1명 확정 (대표자 이슬기 본인도 가능)
어떻게:
  • 학사학위 이상이면 자격 충족 (4년제 대학 졸업증명서 준비)
  • 기사·산업기사 자격증 보유자도 가능
  • 해당 인원은 연구 업무 100% 전담 지정 (타 업무 겸직 불가로 기록)
준비 서류: 졸업증명서 또는 자격증 사본, 재직증명서 (자체 발급)
2

연구공간 지정 및 구획 분리

무엇을: 현재 사무실 내 연구 전용 공간 지정 (10층 77-4호 내부)
어떻게:
  • 책상 1개 이상 + 컴퓨터를 "연구전담공간"으로 지정
  • 파티션, 팻말, 라인테이프 등으로 일반 업무공간과 물리적 구분
  • "연구개발전담부서" 명패 부착 (인쇄 후 출력 가능)
  • 공간 전경 사진 촬영 (정면·측면·명패 포함)
준비 서류: 연구공간 배치도 (손으로 그린 도면도 가능), 공간 사진 3~5장
3

전담부서명 및 연구분야 확정

무엇을: 신고서에 기재할 부서명과 연구분야 결정
어떻게:
  • 권장 부서명: "동행 전자상거래연구개발팀" 또는 "동행 유통기술연구부"
  • 연구분야: "전자상거래 플랫폼 기술 / 유통 물류 자동화 / 소재부품 품질관리"
  • 향후 신청할 R&D 과제와 연구분야를 일치시키는 것이 중요

PHASE 2 — 신청 단계 (3주차)

4

RNDIP 온라인 신청

단계별 클릭 순서:
  1. rndip.or.kr 접속 → 기업 회원가입 (사업자등록번호 609-35-66188 입력)
  2. 로그인 후 "연구소/전담부서" → "설치신고" 메뉴 클릭
  3. 신고 유형: "연구개발전담부서" 선택 (기업부설연구소 아님)
  4. 기업 정보 자동 입력 확인 → 부서명·연구분야 입력
  5. 연구전담요원 정보 입력 (성명·생년월일·학력·연구전담 여부)
  6. 서류 업로드: 사업자등록증·졸업증명서·재직증명서·배치도·공간사진
  7. 최종 제출 → 접수번호 저장
5

심사 대기 및 보완 대응

대기 중 해야 할 일:
  • 처리기간: 영업일 기준 약 7~14일
  • RNDIP에서 보완 요청 문자/이메일 수신 시 7일 이내 추가 서류 제출
  • 대기 기간 중 과제 1 신청 준비 병행 가능
✓

인정서 수령 → 즉시 활용 시작

수령 후 바로 할 일:
  • 인정서 사본 5부 복사 보관 (각 R&D 과제 신청 시 첨부)
  • 연구비 전용 계좌 개설 (거래 은행에서 별도 통장)
  • 연구일지 작성 시작 (매 연구일 빠짐없이 작성)
  • 세무사에게 연구개발비 세액공제 적용 알림
과제 1

창업성장기술개발사업

지원규모: 최대 1억원/년 (2년) 주관: 중소벤처기업부 · TIPA 신청: smtech.go.kr

업력 7년 이하 기업 대상. 동행(2026.02 개업)은 지금 신청이 가장 유리한 시점. 전담부서 등록 없이도 신청 가능하나 등록 시 가점.

연구 과제명: "AI 기반 상품 종합 도매·소매 통합 전자상거래 플랫폼 개발 및 실증"

PHASE 1 — 사업 공고 확인 및 준비

1

공고 확인 및 일정 파악

  • smtech.go.kr 접속 → "사업공고" 메뉴 → "창업성장기술개발" 검색
  • 상반기(3~4월) / 하반기(8~9월) 공고 확인 → 다음 공고 일정 메모
  • 사업 설명회 일정 확인 후 참석 (TIPA 주관, 온라인 참여 가능)
2

기술개발계획서 (사업계획서) 작성

핵심 서류. 합격의 90%를 결정합니다.
필수 포함 내용:
  1. 기술의 필요성: 현재 상품 종합 도매업의 비효율 문제 (수기 재고관리, 느린 발주 등) 데이터로 제시
  2. 개발 목표: AI 기반 플랫폼 기능 명세 (재고 자동예측 정확도 ○○% 달성 등 수치 포함)
  3. 개발 방법: 월별 세부 개발 계획 (Gantt Chart 형식)
  4. 시장성: 국내 B2B 전자상거래 시장 규모 통계 인용
  5. 사업화 계획: 개발 완료 후 매출 계획 (3년 예상 매출)
제출 서류: 기술개발계획서, 사업자등록증, 대표자 이력서, 재무제표 (최근 1년)
3

온라인 신청 제출

  1. smtech.go.kr → 로그인 → 공고 선택 → "신청하기"
  2. 기업 정보 입력 (사업자등록번호, 업종, 개업일 등)
  3. 계획서 파일 업로드 (PDF, 용량 제한 확인)
  4. 공동연구기관 있을 경우 추가 입력
  5. 제출 완료 → 접수증 출력 보관
4

발표 평가 준비

  • 서류 심사 통과 시 대면 발표평가 안내 수신 (평균 15~20분)
  • 발표 자료 (PPT) 준비: 문제 정의 → 기술 설명 → 개발 계획 → 기대효과
  • 예상 질문 대비: "왜 이 기술이 필요한가", "개발 가능성 근거", "매출 달성 방법"
과제 2

중소기업 기술혁신개발사업

지원규모: 최대 2억원/년 (1~3년) 주관: 중소벤처기업부 · TIPA 신청: smtech.go.kr

전담부서 또는 기업부설연구소 보유 기업 필수. 과제 0 완료 후 신청. 지원 금액이 크고 경쟁률 높으므로 사업계획서 품질이 핵심.

연구 과제명: "금속 파스너·수공구 스마트 유통관리 시스템 개발 및 품질인증 자동화 연구"
⚠️ 선행 조건: 연구개발전담부서 인정서 보유 (과제 0 완료 필수)

단계별 실행 절차

1

기술 차별성 자료 수집

  • 국내 금속 파스너 시장 현황 자료 수집 (한국무역협회, KOTRA 보고서)
  • 경쟁사 제품·서비스 분석 (차별성 근거 확보)
  • 특허 선행기술 조사: kipris.or.kr → "금속 파스너 품질검사" 검색
  • 특허 없을 경우 출원 검토 (신청 시 큰 가점)
2

기술개발계획서 작성 (심화)

과제 1보다 기술 수준이 높아야 합니다:
  1. IoT 센서·영상인식 기술 활용 방법 구체적 기술 (특허 인용 가능)
  2. 개발 단계별 성능 지표 수치 명시 (예: 불량 검출율 99% 이상)
  3. 외부 전문기관 협업 계획 (대학 연구소, 기술원 등) 포함 시 가점
  4. 시제품 → 양산 → 매출 연결 로드맵
3

smtech 신청 및 평가 대응

  • 공고 확인 → 신청 → 서류심사 → 발표평가 → 협약 체결 순 진행
  • 선정 후: 연구비 집행 계획에 따라 지출 + 연구일지 매일 작성
  • 중간 점검(6개월) · 최종 보고서 제출 의무
과제 3

소재·부품·장비 기술개발사업 (소부장)

지원규모: 3~10억원 (2~4년) 주관: 산업통상자원부 · KEIT 신청: keit.re.kr / itech.keit.re.kr

금액이 가장 크고 심사가 가장 까다로운 사업. 전담부서 운영 실적 최소 6개월 이상 후 신청 권장. 단독 신청보다 대학·연구소 컨소시엄 구성 필수에 가까움.

연구 과제명: "국내 금속 파스너 품질 자동검사 및 규격 인증 시스템 개발"
⚠️ 선행 조건: 전담부서 인정서 + 운영 실적 6개월 이상 + 컨소시엄 파트너 확보

단계별 실행 절차

1

컨소시엄 파트너 탐색

  • 인천대학교·인하대학교 산학협력단 접촉 (소재공학과, 기계공학과)
  • 한국생산기술연구원(KITECH) 인천 지역본부 협업 문의
  • 주관기관(동행) + 참여기관(대학 연구소) 구조로 컨소시엄 구성
2

사전기획 및 RFP 분석

  • KEIT 홈페이지에서 소부장 RFP(연구과제 기획서) 열람
  • 당사 기술과 매칭되는 품목 찾기 (금속체결요소, 기계부품 등)
  • 기술료 조건·지식재산권 귀속 조건 사전 확인
3

itech 시스템 신청

  • itech.keit.re.kr 접속 → 공고 선택 → 컨소시엄 구성 등록
  • 연구개발계획서(기술+사업화) + 연구팀 구성 + 예산 계획서 제출
  • 발표 평가: 기술 전문가 5인 이상 패널 평가 (전문적 기술 설명 능력 필수)
과제 4

디지털 전환 촉진 R&D 사업 (K-Digital)

지원규모: 1~3억원 (1~2년) 주관: 과기정통부 · NIPA 신청: nipa.kr

전자상거래 업종 기업에 최적. AI·빅데이터 도입 계획만 구체적이면 신청 진입장벽이 낮음. 전담부서 등록 후 즉시 신청 가능.

연구 과제명: "전자상거래 도매 플랫폼 AI 수요예측 및 자동발주 시스템 연구개발"
1

현재 디지털 현황 분석 자료 준비

  • 현재 재고관리 방식 문서화 (수기·엑셀 등 비효율 증빙)
  • AI 도입 후 기대 효과 수치화 (처리시간 ○○% 단축 등)
  • 활용할 AI 기술 스택 명시 (Python ML 라이브러리, 클라우드 서비스 등)
2

NIPA 공고 신청

  • nipa.kr → 사업 공고 → "디지털 전환" 키워드 검색
  • 계획서 제출 → 심사 → 협약 (비교적 간소한 절차)
과제 5

수출지향형 중소기업 혁신바우처 (인천 우대)

지원규모: 최대 3천만원 주관: 중기부 · 인천광역시 · ITP 신청: itp.or.kr / 중기부 바우처 포털

인천 소재 기업으로 지역 가점 보유. 바우처 방식으로 절차 간소. 글로벌 판로 개척 연계 가능.

연계 과제명: "중소 도매기업 글로벌 전자상거래 수출 경쟁력 강화를 위한 다국어 B2B 플랫폼 개발"
1

인천테크노파크(ITP) 상담 신청

  • itp.or.kr 또는 ☎ 032-260-0500 → 바우처 사업 담당자 연결
  • 인천 소재 증빙 (사업자등록증) + 수출 계획서 제출
  • 바우처 승인 후 지정 공급기관(개발사)에서 플랫폼 개발
